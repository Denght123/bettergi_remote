# Visual asset provenance

`spring-adventure-party.webp` and its mobile crop are optimized derivatives of the spring celebration screenshot supplied by the project owner on 2026-09-10. `paimon-guide.webp` is an optimized derivative of the supplied Paimon screenshot. The Windows agent ships JPEG derivatives of the same two images because Windows GDI+ does not reliably decode WebP.

The depicted characters, artwork, Genshin Impact name, and related copyrights belong to miHoYo/HoYoverse and their respective creators. They are used only to identify the game supported by this non-commercial, unofficial community utility. BetterGI Remote is not affiliated with or endorsed by miHoYo/HoYoverse.

## UI typography (2026-10-04)

`manrope-latin.ttf` is a locally served Manrope font from Google Fonts. License: SIL Open Font License 1.1, included in `Manrope-OFL.txt`. Chinese text falls back to installed Microsoft YaHei UI / PingFang SC. There are no third-party font requests during normal use.
