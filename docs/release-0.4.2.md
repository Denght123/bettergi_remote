# BetterGI Remote 0.4.2

发布日期：2026-10-04。

## 界面更新

- 全浅色移动端和桌面；自绘应用窗口标题栏，维持拖动、缩放、最大化/还原、最小化、关闭和默认确认按钮结果。
- 私有加载 Remote UI Sans（Noto Sans SC 改名子集）字体；桌面常规 400、标题 medium 500；网页自托管中文字体和 Manrope。
- 统一 Fluent Regular 功能图标、细线边界、输入框垂直居中、按需帮助和低频管理折叠。
- 手机导航和页面切换动效不重启状态刷新动画，支持 reduced-motion；所有既有 RPC、编辑草稿、任务排序及传输契约保留。
- 更新和错误提示统一主题、改善字色对比；不隐藏风险或材料来源限制。

## 滚动性能修复

删除每个 OnScroll 的 Invalidate(true)，使用原生暴露区刷新；卡片背景改为不透明绘制，防止透明子控件递归重绘祖先。没有屏幕截图缓存，不影响真实输入与光标。

受控同机、同窗口、同滚动范围 662、8 个输入字段，180 模拟 ThumbTrack（60 预热+120 计时）：平均 39.28 → 8.76ms；P95 77.19 → 14.38ms；重绘 27207 → 5436 次。该数据是处理耗时，不等同用户设备显示帧率。主窗口截图像素差均值为 0。

## 验证与边界

- .NET 81、PWA 15 与 Go 测试；Windows Release 构建无警告错误，最终正式验证以 HANDOFF.md 记录为准。
- 实际 UI 字体加载、输入居中、确认结果与不同宽度检查；手机小数输入、草稿保留、键盘排序、演示启动/停止、reduce-motion 已验证。
- 后端源/协议/存储/加密未改行为；仅发布 AgentVersion 等版本元数据从 0.4.1 更新至 0.4.2。
- 演示数据不代表游戏实际收获；没有将自动测试当成真实游戏执行验证。
- 不自动覆盖用户本机安装；旧版本用户需要正常退出旧客户端后安装补丁，绑定和本地设置按原有安装行为保留。
- 安装包未进行商业代码签名，SHA-256 会在打包后写入 README 和公网更新清单。
