# Visual asset provenance

`genshin-character-ensemble.webp` and its portrait mobile variant `genshin-character-ensemble-mobile.webp` are locally composed decorative banners featuring Sandrone, Hu Tao and Nahida. They were assembled on 2026-09-10 from character-only images collected from public character-art pages, including Enka.Network assets and HoYoWiki/米游社 image pages. The shipping images contain no source-page navigation or descriptive text.

The depicted characters, artwork, Genshin Impact name, and related copyrights belong to miHoYo/HoYoverse and their respective creators. They are used only to identify the game supported by this non-commercial, unofficial community utility. BetterGI Remote is not affiliated with or endorsed by miHoYo/HoYoverse.

The Windows agent ships a JPEG derivative at `agent/src/BetterGI.RemoteLite.Agent/Assets/genshin-character-ensemble.jpg` because Windows GDI+ does not reliably decode WebP. The web interface continues to use the smaller WebP variants.
