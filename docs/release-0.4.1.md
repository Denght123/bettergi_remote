# BetterGI Remote 0.4.1

## 更新检查与下载修复

- 更新源与控制服务地址分离，本地测试或自定义控制连接不会被误用为发布清单来源。
- 主更新源返回 HTML、损坏 JSON、缺字段或无效摘要时自动尝试 GitHub 备用源。两个来源均不可用时显示可读中文原因，不暴露 JSON 行号/字节位置。
- BetterGI 本体版本检查共用同一防御性处理，支持有效的预发布版本号。
- 修复 Windows 上校验流尚未关闭就移动下载文件的问题；写入、校验均关闭后才将临时文件替换为安装包。
- 下载检查 HTTP 状态、内容类型、内容长度、SHA-256 和 Windows 安装包文件头，异常下载不会覆盖已有可信包。
- 重复点击检查更新有单次操作保护；启动、执行、停止和保存期间不安装更新。
- 服务端未配置更新目录时，更新/下载保留路径返回明确错误，不再返回 SPA 首页 HTML。

## 验证

- .NET 81 项测试、PWA 12 项测试、Go 测试全部通过；Windows Release 构建零警告、零错误。
- 使用真实正式更新地址完成检查；控制地址设置为本地 18080 时，更新地址仍为正式 JSON 服务。
- 新增 HTML/异常 JSON 回退、类型错误、缺字段、取消、不完整与不可信下载、Windows 文件移动和临时文件清理回归。
