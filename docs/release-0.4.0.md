# BetterGI Remote 0.4.0

## 启动与停止

- BetterGI 未启动时自动打开并执行远程任务；已启动时确认空闲并优先复用适用的全局一条龙快捷键，否则正常重启空闲实例后执行。
- 收到对应配置的任务日志确认后才进入执行状态，启动、保存与停止均有明确反馈。
- 停止请求期间显示“等待停止确认”，防止重复发送快捷键；已经结束的任务不再误提示停止指令已发送。
- 识别官方取消日志，手动停止后的剩余任务标记为跳过，不误报成功。

## 配置与报告

- 手机增加全局任务设置、脚本调度和已安装 JS 脚本参数分类，支持搜索、按组展开、小数输入、草稿保护与键盘排序。
- 配置和长材料报告分页读取，保持修订/任务一致，并遵守原有 48 KiB 加密明文上限。
- 实时展示任务、步骤、脚本/路线位置，提供中文失败原因和处理建议；日志有 JS 行号时展示对应行号。
- 奖励数量支持各种已识别物品，木材估算与交互/拾取识别次数分开列出；飞书与 QQ 邮件采用同一来源说明。
- 新版网页提示旧电脑端升级，现有绑定可继续保留。

## 验证与限制

- .NET 66 项测试、PWA 12 项测试、类型检查、构建及 Go 测试通过。
- 本机只读同步 4346 个配置字段，68 页完整读取，最大页 22605 字节。
- 手机/桌面界面及停止日志回归通过；未自动消耗游戏资源进行本轮完整实机任务验证。
- 电脑端所有界面并未全部移植，代码/文件操作、凭据和复杂脚本控件仍在电脑端处理。
- 拾取日志没有真实入包数量时仅记录识别次数，不等同实际新增；木材数量明确标为估算。
- 自动正常重启需要关闭“关闭时最小化到托盘”，且不能有活动任务、桌面分身或阻塞对话框。
