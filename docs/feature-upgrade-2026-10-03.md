# 本轮功能优化与验证记录

日期：2026-10-03。基线为 v0.3.5，本轮以 v0.4.0 发布；具体发布结果记录于 HANDOFF.md。

## 启动流程

- 手机不再因为 BetterGI 已打开而禁用启动按钮。
- BetterGI 未打开时使用官方 `startOneDragon "配置名"` 入口自动打开并执行。
- 已打开时先根据对应进程的日志确认没有独立任务、一条龙或连续调度正在运行。
- 已选中远程配置，且配置了可验证的 Ctrl+Shift+功能键全局一条龙快捷键时，复用现有实例。
- 不具备上述条件时，正常关闭空闲实例，再通过官方入口载入远程配置并启动。不会强制结束进程。
- 必须收到 BetterGI 日志中精确匹配的“启用一条龙配置：远程每日”才进入执行状态；90 秒仍未确认时返回可读原因。
- 启动与保存共用操作锁，任务执行中不修改配置；重复点击不启动第二次。

实际限制：BetterGI 0.65/0.66 的已运行实例激活处理没有注册 task.*，不能把发送命令后的进程创建成功当作任务已运行。若开启“关闭时最小化到托盘”，且不能复用已配置的一条龙快捷键，正常重启分支会要求在电脑端关闭该选项。桌面分身、其他路径实例、权限不同或活动日志不足时也会明确拒绝，避免中断电脑任务。当前电脑此托盘设置为关闭。

## 配置范围

保留远程一条龙任务列表、开关、排序、现有参数与固定完成动作，扩展三类配置：

| 类别 | 本轮实现 |
| --- | --- |
| 全局任务参数 | 自动拾取、自动剧情、钓鱼、快速传送、伐木、吃药、烹饪、战斗、独立秘境、独立首领讨伐、七圣召唤、圣遗物分解、演奏、地图追踪、脚本订阅以及捕获/遮罩显示参数 |
| 调度器配置组 | 已安装 JS/键鼠/地图追踪任务的启用状态、执行周期、次数、顺序；配置组地图追踪、战斗、赶路与跳过规则 |
| JS 脚本参数 | 从已安装脚本 manifest 和 settings_ui 读取文本、复选、选择、多选字段，并写回该配置组的 jsScriptSettingsObject |

字段由电脑端按已存在的键和已安装脚本元数据生成，包含中文标签、类型、范围和选项。修改保留未知字段，并备份参与的文件；一条龙、全局、调度文件和脚本设置元数据共同参与修订检查。脚本和目录链接不能逃逸 BetterGI 的对应目录。

界面提供分类、搜索、按组展开、小数输入、未保存提示与草稿保护。大配置分页传输，同一次读取使用固定修订的快照，保存前重新核验实际文件；消息仍遵守原有 48 KiB 明文上限。仅传递改动参数，避免保存时覆盖未修改选项。分组一次遍历生成，展开时才创建表单控件，减少大量脚本参数的页面开销。

范围限制：这不是电脑 BetterGI 所有界面的完整移植。Shell/脚本代码编辑、文件上传、新建/删除脚本、任意文件路径、通知凭据和网络授权不从手机开放；更复杂的自定义设置控件仍需电脑操作。保存全局参数时需空闲实例重新加载，不能宣称写磁盘后立即在运行任务中生效。

## 实时状态与失败定位

- 展示准备/执行阶段、当前任务、脚本或路线、当前步骤以及任务列表状态。
- 识别一条龙和配置组分别计数，避免混合任务列表错位。
- 支持前往地点、切换队伍、战斗、领奖、奖励识别、采集和伐木等步骤。
- 错误展示任务、最后明确的步骤/位置和处理建议；日志提供 JS 行号时转换为“某脚本第几行失败”。
- 堆栈和技术诊断保留在电脑端，手机和通知展示中文说明。
- 状态快照携带当前进度，手机重连后可恢复；通知发送不再拖延任务完成状态。

未提供具体路径点/脚本行号的日志不能凭空推断位置，界面显示最后可以确认的步骤。

## 物品统计

统计不限于摩拉和圣遗物，BetterGI 奖励识别输出的任意物品名称与数量均可汇总，并按电脑本地日期累计。报告分开呈现：

- 奖励识别数量：进入本次和今日累计。
- 木材估算：累计 OCR/轮次结果只记增量，避免把 3、6、6 相加为 15。
- 交互/拾取记录：显示物品识别次数，明确可能包含对话、重复识别，不能等同实际新增数量。

飞书与 QQ 邮件采用同一报告格式，包含失败步骤、材料、木材估算与拾取记录。长材料报告分页传输，原始日志不随手机报告下发。

准确性限制：上游 AutoPick 的“交互或拾取”是操作日志，不是背包入库接口。邮件、采集脚本等没有提供真实数量时，当前实现不伪造数量，也不把未记录当作零。覆盖全部物品的精确新增量还需要可靠的入库事件或任务前后背包数量数据。

## 验证

最终测试数量和构建结果记录在 HANDOFF.md。本轮增加的测试覆盖：

- 已运行实例的空闲/忙碌判定、进程与日志归属、启动确认、快捷键适用条件。
- 全局/调度/JS 参数读写、敏感字段排除、未知字段保留、修订冲突、无效参数不落盘。
- 独立任务计数、路线错误定位、JS 行号、材料名称、木材去重和拾取来源区分。
- 配置与报告分页、混合修订/任务拒绝、大小限制、前端草稿及启动条件。
- 390、320 和 1280 像素的浏览器检查；分类、搜索、小数输入、运行任务及报告画面。

只读检查当前真实 BetterGI 配置成功，读取到超过四千个字段，覆盖大量调度与脚本参数，没有修改真实配置。没有消耗树脂、实际启动游戏任务、覆盖用户安装或部署生产环境。正常关闭/重启和真实游戏执行仍需安装候选客户端后做短任务灰度验证。
